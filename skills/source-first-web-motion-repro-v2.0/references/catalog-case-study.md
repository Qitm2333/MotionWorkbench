# 目录展开动效：本次实战案例

参考：`https://dmcg.co/archive?family=brand-design`。分析日期：2026-10-21。

这是一个特定版本的案例，不是对所有网站适用的参数模板。网站可能更新，未来必须重新检查实际加载的资源。不要将此文当成当前网站仍使用这些代码的保证。

## 问题到底是什么

用户要的是“单击分类目录，卡片从节点冲出去”的质感。最初实现把重点放在卡片详情打开，还使用手写百分比坐标、随意旋转和普通缓动，漏掉了目录点击。这是任务识别和证据链的双重错误。

正确起点是找到分类按钮的点击逻辑，然后向外追踪到路由状态、布局算法、相机、卡片动画和连线。

## 确认过的行为与参数

| 项目 | 源码证据 |
| --- | --- |
| 路径 | 空对象或含 `family` 的对象 |
| 当前分类再次点击 | 目标为空路径，收起 |
| 点击其他分类 | 直接切换；旧卡退出与新卡进入允许重叠 |
| 根节点点击 | 返回空路径 |
| 键盘 | Escape / Backspace 返回空路径 |
| URL | `replaceState` 同步 `family` |
| 分类 | `brand-design`、`product-design`、`physical-design` |
| 窄屏 | 宽度不大于 900px 强制 Grid |
| 布局单位 | `max(1, viewportWidth / 1900)` |
| 节点高 / 行间隔 | `35 * unit` / `58 * unit` |
| 根到分类间隔 | 桌面 `72 * unit` |
| 相机 | 1.05 秒，贝塞尔 `[.22, 1, .36, 1]`；桌面选中分类垂直居中 |
| 卡片进入 | 延迟 `.26 + .024 * min(order, 40)` 秒，order 为离分支原点距离排序 |
| 进入弹簧 | stiffness 64、damping 15、mass 1 |
| 位置 | `origin + (layoutPosition + drift + hoverPush - origin) * progress` |
| 缩放 / 透明度 | `(.38 + .62 * progress) * grow` / `min(1, 1.6 * progress)` |
| 卡片退出 | progress 回到 0，.42 秒，同相机缓动；约 430ms 后移除 |
| 连线 | 同一帧读取卡片当前位置、尺寸和缩放，连接到卡片边缘 |
| 漂移 | 两轴低幅正弦，按卡片种子生成幅度、周期与相位 |
| 悬停 | 放大 `max(1.12, 196 * unit / width)`，周围卡片碰撞避让 |
| 画布拖动 | 超过 6px 才启动，结束后拦截误触 click |
| 未展开时 hover | ghost 卡片与虚线预览；不是旧卡退出的残影 |

散布函数的关键不是“随机撒几张”：它使用 ID 种子、媒体宽高比、大小权重、分支附近椭圆禁区和候选点选优，然后进行最多 6 轮缩小尝试，每轮 220 次矩形碰撞分离，最后按离原点距离排序。

## 不要重复的实现错误

- 收起传入空路径后仍访问 `families[null].projects`，会直接崩溃。空路径必须是合法状态。
- 从已经经过相机变换的 DOM rect 测量坐标，再给连线施加同样变换，会重复偏移。
- 节点用百分比、卡片用局部像素、连线用屏幕像素，三个坐标系会随相机移动脱离。
- 先等待全部旧卡退出再显示新卡，会改变原站节奏。
- `stroke-dasharray: 1` 必须匹配 `pathLength=1` 或真实路径长度；不存在有效的 CSS `path-length` 属性。
- ARIA current 应设有效值或删除属性，不能仅用空字符串切换属性存在性。
- 同一 key 退出时马上创建新实例，会覆盖状态映射并留下孤儿 DOM；要能恢复该实例或对退出实例单独编号与清理。
- reduced-motion 应让状态、漂移和悬停动画一起稳定，而不是只关闭 CSS transition。
- 验证视口只有 878px 时，原站规则就是 Grid；不能把看不到树当作树逻辑坏了。

## 已完成与未完成要分开说

本次确实读取了压缩源码，并以此替换了本地核心布局和运动机制。语法检查通过，也读到了本地新 DOM。用户随后反馈效果已经很好。

但是当时没有完成 1440px 桌面全流程自动点击验收；尝试启动桌面无头浏览器时被用户拒绝。不能把它写成“所有桌面交互已验证”。占位卡片、字体、数据数量和部分外围交互也不等同原站。

这个案例的可复用成果是证据优先的工作法，以及状态、布局、相机、逐帧表现四层拆分；不是保证复制一组参数就能复原任何网页。
